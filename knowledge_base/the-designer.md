# The Designer

### **The Docomotion Designer**

**Overview:** The Docomotion Designer is a fundamental component that facilitates the design, testing, and uploading of Forms within the Docomotion environment. Leveraging the capabilities of MS-Word, the Designer provides extensive functionalities, including headers, footers, styling, pagination formats, symbols, and more.

To open the Designer:

1. Open the Docomotion App in Salesforce.
2. In the Forms tab, select the desired form.
3. Click “Open Designer”

### **Describing the Designer Window**

All form design, component creation, and testing activities are conducted within the Designer window. In the Detailed Designer Window Description section, you’ll find comprehensive information about the various Designer elements, panels, and the overall workspace.

**The Designer Window:**

**Designer Parts:** The Designer window presents the following key elements:

1. **Top Menu Bar:**

   - Utilize shortcut buttons for the following actions:
     - Undo (Undo): Revert the last action performed in the form (before saving).
     - Redo (Redo): Reverse the undo actions.
     - Quick Test Preview (TestPreview): Generate an instant visual or printed test preview based on default project settings.
     - Save (Save): Save all changes made to the form.
     - Upload to Cloud (Upload): Upload the Form to the cloud.
2. **Form Data Tags Panel (Upper Left Window):**

   - Displays all tags currently in use in the Form.
   - Actions you can perform from the Form Data Tags Panel:
     - Delete Form Tags.
     - Define Tag Properties.
   - Selection of a tag in this panel also highlights associated tags in the Data Repository and Form Design panels.
3. **Data Model Tags Panel (Bottom Left Window):**

   **‘Repository Data Tags’ tab:** This tab encompasses:

   - **List Selected data tags:** Defined during the creation of the data model.  (see ‘[Create Data-Model](https://www.docomotion.com/support/create-a-data-model/)‘ for reference).
   - **Special tags:**
     - Container  (See ‘[Working with Container](https://www.docomotion.com/support/container/)‘ for reference)
     - Script Tag
     - Group Table
     - Chart Tag
     - Table Block

   **‘Interactive Collection’ tab:** Within this tab, you’ll find:

   - **Interactive data tags:** Added as “Interactive fields” during the data model creation.
   - **Interactive Collections data tags:** Those associated with the form. (See ‘[Interactive Collections](https://www.docomotion.com/support/interactive-collection/)‘ )

   **Actions you can perform from the Data Model Tags Panel:**

   - **Insert tags into the Form:** Easily integrate tags into the form for enhanced functionality.
   - **Set Test Values:** Streamline testing processes by configuring test values directly from the panel.
4. **Search Panel:**

   - The Designer Search Engine helps locate specific tags within:
     - Form Data Tags Panel.
     - Data Model Tags Panel.
     - The Form.
5. **Workspace:**

   - The Workspace is the primary area where you design your form, utilizing all available design options in Word.
