# Salesforce Interactive Fields

[Video](https://youtu.be/AIygYGDiiJo)

- Notice: Before you start make sure you have authorized Docomotion to update Salesforce data. See ['Authorizing to interact with Salesforce data'](https://www.docomotion.com/support/docomotion-for-administrators/authorizing-to-interact-with-salesforce-data/).

### **Updating Salesforce Data**

**Step 1: Adding Interactive Fields to a Data Model**

- - When creating a Data Model for Forms, Salesforce fields can be added as Applicative or Interactive.
  - Interactive fields allow recipients to change values and submit updates, reflecting changes in Salesforce.
  - Select fields from the Available Fields pane, and they appear in the Selected Fields pane.

**Step 2: Adding Interactive Salesforce Fields in Designer**

- - - Open the Designer in Salesforce.
    - Click at the location in the Form to place the tag.
    - In the Data Model panel select the **Interactive tab**.
    - Click on the required object to expand the view of all available fields.
    - Double-click to insert the required field into the Form.
    - Insert the Submit button to enable information updates in Salesforce.
    - Design the Form as needed and preview it.

- Notice: In some cases, i.e. when needed to add a Signature field to a form, you will need to create a 'Interactive Collection' and incorporate it to the form. For additional details see ['Interactive Collections'](https://www.docomotion.com/support/docomotion-for-designers/interactive-capabilities/interactive-collection/).
