# Form: Definition

The Form is the basic entity of Docomotion. Forms are templates that are used for generating output documents. They combine static content, Salesforce variable data, and scripts.

Forms are designed using the Docomotion Designer tool. Once the Form is designed and saved to Salesforce, the Form object includes four files directly associated with this Form: DataSchema.xml, Document.ffx, Preview.pdf and Metadata.xml (the four files are generated per Form). These files are saved in Notes&Attachments and you can see them in the organization’s Data Management view (Storage Usage). It is crucial that these files not be deleted.

Following the Design stage, after activation, Forms can be used for generating output. The Runtime engine uses the Form (template), incorporating Salesforce variable data (called tags in Docomotion), to produce the final output in a variety of channels (PDF, Word, HTML, email).
