# Barcode Integration and Tag Properties

**Barcode Integration and Tag Properties**

You can seamlessly integrate barcodes into Salesforce by adding a barcode field as a barcode data tag to your form. This allows you to apply various barcode standards, enabling dynamic barcode generation during the production stage.

**Barcode Output:** To view and modify tag properties:

1. In the Form Data Tags panel, right-click the data tag and select Properties.
2. Choose the Bar Code tag type.
3. Open the Standard dropdown menu and select an option based on barcode design requirements.
4. To rotate the barcode in the form, open the Rotation dropdown menu and select the desired degree of rotation.
