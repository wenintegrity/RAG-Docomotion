# Adding Pictures to a Form

- Supported picture file formats are: PNG, BMP, JPEG and TIFF.

There are several options for adding pictures to the Form:

- Pictures stored as a Salesforce document. Note that the pictures need to be available to the Docomotion servers, so you need to make sure the pictures are available externally. See**[Saving Pictures inside Salesforce](https://www.docomotion.com/support/pictures-from-external-repositories/).**
- Pictures from an external repository. See**[Adding Picture Scripts](https://www.docomotion.com/support/adding-picture-scripts/).**
- Pictures from Notes and Attachments or Salesforce Files. See **[Adding Pictures from Notes & Attachments or Salesforce Files](https://www.docomotion.com/support/pictures-from-notes-and-attachments/)**.
