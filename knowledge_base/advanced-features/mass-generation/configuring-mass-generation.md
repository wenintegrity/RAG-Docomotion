# Adding Mass Generation Button to Standard Objects

### Mass Generation Button

The “Lightning Mass Generation” button is available for standard Salesforce objects (e.g., Accounts, Opportunities, Leads, Contacts), and can be added to the layout of the List View, and to Related Lists.

- Notice: To use the Mass Generation feature you need to authorize Docomotion to update Salesforce data. Refer to '[Authorizing to interact with Salesforce data](https://www.docomotion.com/support/docomotion-for-administrators/authorizing-to-interact-with-salesforce-data/)'.

### **Adding the Mass Generation Button to the Related-Lists**

To include the Mass Generation button for bulk document generation from related lists, follow these steps and add the button to the Related Lists Layout of the designated Main Object:

1. As a Salesforce Administrator, access the Salesforce Setup and navigate to the specific Object where you want to include the button.
2. Edit the layout for the chosen object.
3. In the Related Lists section, click the Related List Properties gear-icon.
4. The Related List Properties window will appear.
5. From the Available Buttons pane, choose “**Lightning Mass Generation**“, and click Add to move it to the Selected Buttons pane.
6. Click OK to save the changes.

### **Adding the Mass Generation Button to a List View**

To incorporate the Mass Generation button into the List View, follow these steps:

1. As a Salesforce Administrator, go to the Salesforce Setup and locate the Object where you wish to showcase the button.
2. In the left pane, choose ‘List View Button Layout’ and ‘List View.
3. Choose the “**Lightning Mass Generation**” button from the Available options to the Selected options.
4. Save your changes.
