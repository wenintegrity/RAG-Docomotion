# Release Notes v24

## v24

## Highlights: Advanced Multi-Signer Flows, Extended Data Depth, and Modernized Lightning UI

Version 24 introduces powerful new capabilities designed to streamline complex document workflows and elevate the administrator experience. This release brings advanced multi-signer support, extends data model depth, debuts a completely refreshed Lightning interface, and introduces a more stable Segments architecture.

Below is an overview of the key changes.

### 1. Advanced Multi-Signer (MS) Workflows

We have expanded our multi-signer framework to provide organizations with maximum routing flexibility. Building upon our classic sequential signing chain, Docomotion now supports true parallel execution.

- **Simultaneous Routing:** Send a single document to multiple signers at the exact same time. Signers no longer need to wait in a fixed sequence, dramatically reducing completion turnaround times for non-hierarchical agreements – [Read the complete Multi-Signer Knowledge Base Page](https://www.docomotion.com/support/docomotion-for-designers/interactive-capabilities/multi-signers-2/)

### 2. Extended Data Model Depth (8 Levels)

**Handling deeply nested relational data with ease.** To accommodate complex enterprise data structures, Docomotion’s Data Model now supports data extraction up to 8 levels deep within your object hierarchy.

- **Advanced Relational Extraction:** Pull related records from intricate, deeply nested Salesforce object relationships that were previously inaccessible.
- **Simple Administration:** This expanded depth can be effortlessly configured via the App Settings.
- **Full Backward Compatibility:** The updated architecture is fully backward compatible, ensuring all your classic, existing data models continue to work flawlessly.

### 3. Enhanced UI/UX for Lightning Configuration Screens

**A cleaner, more intuitive interface for administrators and designers.** We have completely overhauled key Lightning configuration screens to provide a modernized design, improved navigation, and a vastly superior user experience. The upgrade introduces a cleaner layout and intuitive configuration flows across the following areas:

- **System Settings**
- **Form Settings**
- **New Forms**

The refined user interface reduces configuration clutter, helping administrators navigate system environments and set up new assets with greater speed and ease.

### 4. Next-Gen Segments Architecture

**Adding flexibility and boosting workspace performance.** We have enhanced our Segments architecture by introducing a new, lightweight placeholder capability to run alongside the classic full-rendering method.

- **Optional Placeholder Workflow:** You can now choose to load compact placeholders (e.g., **S1, S2, S3**) in the Designer instead of heavy visual layouts, significantly accelerating your loading and saving times.
- **Reduced Overhead:** Utilizing placeholders simplifies template maintenance and minimizes document generation complexity behind the scenes.
- **Identical Final Output:** This performance boost is strictly for the admin design workspace. Regardless of whether you use the classic preview or the new placeholder option, the final generated customer outputs (PDF, HTML, Word) remain completely identical and render beautifully.

  [Read the Complete Segments Knowledge Base Page](https://www.docomotion.com/support/docomotion-for-designers/advanced-form-capabilities/subforms/)
