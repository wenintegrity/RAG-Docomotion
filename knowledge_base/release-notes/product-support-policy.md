# Docomotion Product Support Policy & Version Lifecycle

## To maintain optimal performance, security compliance, and full integration with Salesforce updates, Docomotion maintains a predictable support lifecycle for all software releases.

## Support Lifecycle Stages Defined

Docomotion provides clear support lifecycle stages for all official releases.

Stage 1: Active (GA)

### General Availability

Active product release window

- Full tech support
- Feature enhancements
- Bug fixes & security patches
- Full Salesforce Major Release compatibility

Stage 2: End of Support (EOL)

### End of Support / EOL

Post support window

- No technical support provided
- No security or bug updates
- Risk of broken integrations with Salesforce updates
- Immediate upgrade required

## Frequently Asked Questions

Everything you need to know about Docomotion lifecycle policies.

### Why is Docomotion instituting an End of Support policy?

Salesforce releases three major updates per year. To ensure Docomotion remains high-performing, secure, and compliant with Salesforce's evolving security and API standards, we focus engineering resources on modern, supported versions.

### What happens if I continue using an End of Life (EOL) version?

Your document generation templates will continue to function, but support ticket assistance, bug fixes, and critical security patches will no longer be provided. Furthermore, future Salesforce releases may cause un-patched legacy packages to fail.

### How do I upgrade my Docomotion package?

Upgrades are seamless. Administrators can install the latest package directly from the [Salesforce AppExchange](https://appexchange.salesforce.com/appxListingDetail?listingId=a0N30000000pvVBEAY) into Sandbox first, test existing document templates, and then deploy to Production.

### Does upgrading cost extra?

No. All product updates and version upgrades are included free of charge with your active Docomotion subscription.

Note: Free updates apply to all releases within your current subscription tier. Upgrading to a higher license tier will reflect standard tier pricing.
