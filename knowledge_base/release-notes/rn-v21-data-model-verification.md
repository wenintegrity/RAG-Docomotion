# Data Model Verification

Upon upgrading to version V21 or later, it’s sometimes necessary to quickly confirm the integrity of the Data Model. Here’s an easy method to determine if any action is required.

### Steps to Verify Your Data Model:

- Navigate to the Forms object in Docomotion.
- Select your form and open Form Settings.
- Choose ‘Define Data Model’.
- Click Save without making any modifications.
- If you encounter the following warning:

“Warning:

*The Data Model or files structure have been changed. Please open the Designer, check the Form, and save to Salesforce.”*

This indicates that the Data Model requires correction and our support team can resolve the issue promptly! Just submit a ticket to Docomotion Support, including:

- Form ID.
- Record ID.
