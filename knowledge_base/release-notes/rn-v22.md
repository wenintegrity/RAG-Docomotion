# Release Notes v22

## v22

## API Names in Data Model:

We’ve added the ability to view API names directly in the Data Model editor. Administrators and developers can now see technical field and object names without leaving the interface, streamlining configuration and troubleshooting processes. [Read More](https://www.docomotion.com/support/docomotion-for-designers/data-model/create-a-data-model/#elementor-toc__heading-anchor-3)

## One-Click Dual Format Saving

In our Dynamic Word add-in, we’ve added the ability to save both formats (Word + PDF) in one click and support Wording and Clauses with Refresh mode. More details on the different options – [click here](https://www.docomotion.com/support/advanced-features/dynamic-word/)
