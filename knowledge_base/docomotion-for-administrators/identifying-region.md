# Identifying the Docomotion region

## Security Update: Identify Region

Use the following path to find your region details in order to complete your security update:

- In Salesforce go to **Gear icon**  (top-right) → **Setup**.
- In **Quick Find** (left sidebar), type `Custom Settings` → click **Custom Settings**.

- In the list, find **Config** (Namespace doco) → click **Manage**.

- Click **Docomotion Default Settings** .

- Read the **Docomotion Server URL** field.
- Map the URL to a region based on the outcomes below.

**Outcomes:**
`https://salesforce-ir.docomotioninc.com/` = **EU**
`https://salesforce6.docomotioninc.com/` OR `https://oapi6.docomotioninc.com/` = **US**
