# Administrators FAQs

How do I clean up space?

Docomotion uses up a lot of document storage space because it stores previous versions of Forms created when you design a Form. It is therefore recommended that you occasionally perform a clean up operation that removes previous versions.
Clone the Form for which you want to perform cleanup and delete the original Form. This deletes all inaccessible old data. Rename the cloned Form to the original Form name.

Can I intall Docomotion on Salesforce Professional Edition?

No, Docomotion can’t be installed on a professional edition.
If you are new to Salesforce and would like to evaluate the Docomotion solution in a new environment, please send an email to info@docomotioninc.com and we will generate for you a 30 days trial of the Enterprise Edition, on which you will be able to install the Docomotion solution.

How do I check the storage space available to me?

1. In Docomotion click Setup, and then in the left pane Search text box type storage.
2. Click **Storage Usage** to display the Organization limits and usage in the Salesforce page.

How to grant login access to Docomotion Support team?

Please refer to: [Granting Permission to Docomotion Support](https://www.docomotion.com/support/grant-access/)

I know my organization has Docmotion but I cannot see the Docomotion tab

You need a user license in order to use Docomotion (see [Licenses Management](https://www.docomotion.com/support/licenses-management/)). If you do not have the proper authorization form managing Salesforce licenses, check with your system administrator.

Why can't some of the organization users see the 'Generate Document'Button?

Check that these users have a Docomotion license (see [Licenses Management](https://www.docomotion.com/support/docomotion-for-administrators/licenses-management/) ) and the proper permissions (see [Assigning Permissions](https://www.docomotion.com/support/docomotion-for-administrators/assigning-permissions/)).

I added a Signature and Insert 'Additional Document' related list to the record page layout. Why don't I see them in my Lighining record page?

Note that in Lightning, adding any Related  List to the page layout does not automatically display it in the Lightning page.

Verify that you have added the Related Tab to your Lightning page layout, and add the Related  Lists component to this Related Tab.

Only after this, are all related lists you added to the page layout for the record in the Object manager automatically displayed.
