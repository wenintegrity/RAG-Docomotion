# Setting Docomotion Server Region

**Setting Docomotion Server Region during Installation on Salesforce:**

During the installation process of Docomotion within your Salesforce environment, admins are prompted to set the geographic region for the Docomotion Server. If your company is headquartered in the EU, the GDPR requires that all data collected on citizens be either stored in the EU, so it is subject to European privacy laws, or within a jurisdiction that has similar levels of protection.

Options:

1. EU (European Union): Select this option if your business primarily operates within the European Union.
2. US (United States): Choose this option if your operations are centered in the United States.
