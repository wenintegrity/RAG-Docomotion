# Configuration

After installing the Docomotion Connect package, you’ll need to complete several configuration steps to ensure the system works properly.

## Accessing System Settings

Navigate to the Docomotion app and open the **System Settings** section.

## Basic Configuration

Complete the standard Docomotion setup requirements:

- [Configure your Region settings](https://www.docomotion.com/support/docomotion-for-administrators/server-region/)
- [Assign appropriate Permission Sets to users](https://www.docomotion.com/support/docomotion-for-administrators/assigning-permissions/)

## Data Model Configuration

Select **External** as your Data Model Type to enable API-based generation with Docomotion Connect.
