How it works

Answers grounded in the Docomotion knowledge base

A language model on its own doesn't know Docomotion's documentation. This assistant uses Retrieval-Augmented Generation (RAG): it first retrieves the passages most relevant to your question from the support site, then has the model answer from those passages only, citing its sources, or saying "I don't know" when the knowledge base doesn't cover a question.

Building the knowledge base

offline · run once

Prepared ahead of time by export_kb.py and load_data.py, and re-run whenever the website changes.

Step 1

Export

Every page under /support is pulled through the WordPress REST API. Menus and search boxes are removed, and each article becomes a Markdown file with its title, URL and section.

– articles
Step 2

Tag

An LLM reads each article and adds metadata: search keywords and whether it contains code (hasCode), which searches can filter on.

–
Step 3

Chunk

Articles are split at their headings, then into pieces of up to – characters (– overlap). Each chunk starts with "Article > Section" so it still makes sense on its own.

– chunks
Step 4

Embed

An embedding model turns each chunk into a vector of – numbers. Chunks with similar meaning get vectors that point in similar directions.

–
Step 5

Store & index

Text, vector and metadata go into MongoDB Atlas. A vector search index (cosine similarity) finds the nearest chunks fast, with filters on section and hasCode.

–

Answering your question

live · every message

Watch these steps light up as your question is processed.

Step 1

Embed the question

Your question becomes a vector, using the same model as the chunks so the two can be compared.

Step 2

Vector search

Atlas finds the – chunks closest in meaning to the question, even when the wording differs.

Step 3

Build the prompt

The chunks and their URLs go into a prompt with rules: use only this context, say "I don't know" otherwise, cite sources.

Step 4

Generate

The LLM (–) writes the answer, which appears in the chat with its sources.
