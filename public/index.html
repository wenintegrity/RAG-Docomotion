Docomotion Knowledge Assistant

An example of Retrieval-Augmented Generation (RAG). A language model doesn't know Docomotion's documentation, so before answering, this app retrieves the most relevant passages from the Docomotion knowledge base and gives them to the model as context. Answers are grounded in that text, cite their sources, and the assistant says "I don't know" when the knowledge base doesn't cover a question.

1 · Building the knowledge base offline, once

Done ahead of time by export_kb.py and load_data.py. Run them again whenever the website changes.

1

Export

Every page under /support is pulled through the WordPress REST API. Menus and search boxes are removed, and each article becomes a Markdown file with its title, URL and section.

– articles
2

Tag

An LLM reads each article and adds metadata: search keywords and whether it contains code (hasCode), which can be used to filter searches.

–
3

Chunk

Articles are split at their headings, then into pieces of up to – characters (– overlap). Each chunk starts with "Article > Section" so it still makes sense on its own.

– chunks
4

Embed

An embedding model turns each chunk into a list of – numbers (a vector). Chunks with similar meaning get vectors that point in similar directions.

–
5

Store & index

Text, vector and metadata are stored in MongoDB Atlas. A vector search index (cosine similarity) makes finding the nearest chunks fast, with filters on section and hasCode.

–

2 · Answering a question every message

These steps light up live while your question is processed.

1

Embed the question

The question is turned into a vector with the same model used for the chunks, so the two can be compared.

2

Vector search

Atlas Vector Search finds the – chunks whose vectors are closest to the question's: the most relevant passages, even when the wording differs.

3

Build the prompt

The chunks and their source URLs are inserted into a prompt with rules: answer only from this context, say "I don't know" otherwise, and list the sources.

4

Generate

The LLM (–) writes the answer from the prompt, and it appears in the chat with its sources.

Live trace of your last question
